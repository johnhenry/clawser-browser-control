Clawser Browser Control options

Clawser web app origin

The extension connects to Clawser on https://clawser.erisera.com by default (pair a localhost dev server below). If you host Clawser somewhere else, enter its https origin here (for example https://clawser.example.com), with no path. Only this one extra origin is allowed.


Paired pages

Only pages listed here can use this extension, matched by exact origin (scheme, host and port). Risky capabilities are off until you turn them on for a page.

Waiting to be paired

Pages that asked to connect. Nothing happens until you pair one.


Audit log

Actions pages asked for, newest last. Pages can read this log but cannot clear it.
